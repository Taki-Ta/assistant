# 面经 AI 助手：实施路线与进度

## 1. 计分方法

项目总进度采用阶段加权，不按代码行数计算：

```text
总进度 = Σ（阶段权重 × 阶段完成率）
```

任务只有通过对应验收命令或人工验收才可以勾选。阶段完成率按已完成任务的
权重计算；“正在写”不计为完成。
