# 知引 · 知识库助手前端

React + TypeScript + Vite + Tailwind CSS，调用仓库中的 FastAPI 接口。

## 本地运行

需要 Node.js 22.12+。先启动后端，再在本目录执行：

```sh
npm ci
npm run dev
```

打开终端显示的地址，默认是 `http://127.0.0.1:5173`。在页面设置中填写包含非空
`sub` 的 Bearer Token；可以直接粘贴 Token，或带 `Bearer ` 前缀的值。
Token 保存在 `sessionStorage` 中，不写入源码、环境配置或构建产物。关闭浏览器会话后
需要重新配置；清除或更换凭证会清空页面中的账号数据。

Vite 默认将 `/api` 代理到 `http://127.0.0.1:8000`。如果后端使用其他地址，复制
`.env.example` 为 `.env.local`，修改 `API_PROXY_TARGET` 后重启前端。

## 功能

- 服务端会话列表、切换、新建、删除、历史恢复及分页。
- POST SSE 流式回答、工具执行状态和详情、引用来源。
- Markdown、代码块、回答与代码复制。
- 停止生成，保留当前页面中的部分回答；继续提问时复用会话 ID。
- Enter 发送、Shift+Enter 换行，兼容中文输入法。
- 自动跟随回答；向上阅读时暂停跟随，支持回到底部。
- 手机端折叠侧栏，浅色界面，支持系统减少动画设置。

会话和历史从后端加载，只发送当前输入与会话 ID。前端不构建模型上下文，不在本地
缓存完整历史。当前选中的会话 ID 保存在 `sessionStorage`，刷新时重新查询服务端。
历史中的来源从成功工具结果合并，按 `chunk_id` 去重并保留最高分记录。

## 校验

```sh
npm run test
npm run build
npm run format:check
```

测试覆盖 UTF-8 和 SSE 分片、心跳、终止事件、异常断流、中文输入、取消请求、会话
切换时的过期响应、历史加载、删除及来源展示。API 交互测试使用模拟服务响应。

## 部署

```sh
npm run build
```

将 `dist/` 部署到静态服务器，并将同域 `/api/` 反向代理到 FastAPI。Vite 的开发代理
不会进入构建产物。流式路径的代理必须关闭响应缓冲；读取超时应超过后端 15 秒的
心跳间隔。前端所有接口路径均为相对地址，无需在浏览器端配置服务器密钥。

## 当前限制

登录界面暂时只提供 Token 设置。后端不逐段保存文本增量，因此停止时尚未形成完整
消息的部分回答仅保留在当前页面，刷新后可能消失。当前后端将停止记录为失败轮次。
不支持断线续传、修改提问或重新生成。

后端接口字段与分页方式见 [会话接口说明](../docs/会话接口.md)。
